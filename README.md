# ショート動画制作ミニツール集

VOICEVOXとショート動画の制作を少し楽にする、無料の小さなツール集です。
すべてのツールはブラウザ内だけで処理が完結し、入力した台本・音声・動画がサーバーへ送信されることはありません。

公開ページ: https://yakumo04th.github.io/

## ツール一覧

- **よみちがいチェッカー**（`yomichigai-checker.html`）
  台本の読み間違いやすい語をチェックし、VOICEVOX向けテキスト・SRT字幕・YMM4用CSVに変換します。
- **WAV一括結合＆実測SRT生成ツール**（`wav-merger.html`）
  VOICEVOXの連番WAVの前後の無音をカットして1本に結合し、実測の長さからSRT字幕を生成します。
- **ショート動画UI被り（セーフゾーン）チェッカー**（`safezone-checker.html`）
  YouTube Shorts・TikTok・Instagram ReelsのUIガイドを動画や画像に重ねて、字幕や立ち絵の被りを確認します。

## ライセンス

ツールの利用は自由です。辞書データやコードの改変・再配布も構いません。
